## 작업 시작

```sh
cd /Users/simda/Developer/CardBoardGame
git status
git branch --show-current
git remote -v
git fetch --prune
git pull --ff-only
```

Unity Hub에서 `CardBoardGame/` 폴더를 프로젝트로 추가하고 Unity `6000.0.50f1`로 연다. 첫 실행 시 `Library/`와 패키지 캐시는 Mac에서 새로 생성한다.

Unity `6000.0.50f1`에는 Unity Hub가 표시하는 알려진 보안 경고가 있다. Windows와 동일 버전 유지 및 개발환경 재현을 위해 이 버전을 사용하며, 배포 전에는 별도의 업그레이드 검토가 필요하다.

비영어권 Editor 언어에서 Unity 6000.0의 Pixel Perfect Script Updater 오류가 발생할 수 있어 이 Mac에서는 Editor 언어를 English로 설정했다. 패키지는 저장소에 잠긴 공식 호환 버전을 유지한다.

## 작업 종료

Unity Compile, 실행, 관련 테스트를 통과한 뒤 `git status`와 `git diff`를 검토하고 Commit 및 Push한다. Secret, `Library/`, `Temp/`, `Logs/`, `obj/`, `UserSettings/`, `.DS_Store`는 Commit하지 않는다.

현재 프로젝트에는 Unity Test Framework 테스트 케이스가 없어 자동 테스트 결과는 `NOT_AVAILABLE`이다. macOS Player 빌드와 `LobbyScene` 실제 실행으로 검증한다.
